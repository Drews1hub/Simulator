    Settings

    Connect live market data

    This copy is running without its data server (for example on GitHub Pages), so it streams real-time US stock trades straight from Finnhub. A free API key is enough.

    1. Sign up free at finnhub.io/register
    2. Copy the API key from your dashboard and paste it below

    The key is stored only in this browser (localStorage) and sent only to finnhub.io (and twelvedata.com if you add that key).
